## 已观察画面（20秒间隔总览，非逐帧结论）
- 白底带灰暗边缘，粗黑手绘线条，蓝色章标题，红色错误/重点，人物少量彩色填充。
- 真人持笔手叠在画布上，文字和对象逐步建立；不是人物完整肢体动画。
- 约20–40秒：面试桌、提问者、受访者，后续增加信息箭头、人物与负面符号，原图保留形成论证。
- 约60–120秒：第二点，人物对话、问题列表转入 DESCRIPTION 段落；随后局部放大文字以突出重点。
- 约160–200秒：家庭主题，以人物、相框、对话框和 COMMON TOPIC 连接关系。
- 约220–280秒：第四点，犹豫词、表情、机器人与长句对照，用红/蓝/绿区分无意义表达和清晰表达。
- 约300–340秒：第五点，两人对话，逐项列出回应可能性，再加入表情/爱心图形。
- 约360–380秒：缩略汇总前面章节，加入练习提示和订阅图示。
- 下沿持续显示繁体中文字幕，白字深描边，与画布英文关键词分开。
